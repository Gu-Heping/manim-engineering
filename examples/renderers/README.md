# Renderer Examples

Renderer examples show how to choose a visual family externally while keeping
components semantic and renderer-free.

## Catalog

| File | Concept | Components | Run command |
|------|---------|------------|-------------|
| `iec_resistor.py` | IEC renderer selection with rectangular resistor symbols | R1, R2 | `manim --disable_caching -pql examples/renderers/iec_resistor.py IECResistorScene` |

## Smoke check

```bash
python examples/renderers/iec_resistor.py
```
